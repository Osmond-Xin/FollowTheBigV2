# 探索：赚钱模式（预注册，2026-09-03）

> 用户裁定：不限制手段，只用现有数据（1122 天三流 Level-2），目标只有一个——找到一个能赚钱的模式。
> 本文在**看到任何前向收益之前**写下判据。写完之后只追加，不改动。

## 一、判据（用户的五条，落成可算的东西）

一条信号要能跟，必须同时：可归因 · 未完成 · 在价格动之前 · 方向一致跨日持续 · 规模够。
本轮把它压成一个可执行的问题：**在 t 日收盘能算出来的量 X，能不能预测 t+1 开盘买入、持有 N 日的收益，扣掉成本还剩钱。**

## 二、样本、宇宙、成本、方向（先写死）

- **样本切分**：样本内 2022-01-04 → 2024-12-31；**样本外 2025-01-01 → 2026-08-20**。样本外只看一次，看之前不许改因子定义。
- **宇宙**：主板；近 20 日日均成交额 ≥ 1000 万元；上市 ≥ 60 个交易日；当日快照数 ≥ 1000（非停牌）；
  当日未封涨跌停（无卖一/无买一的快照占比 < 50% 且 |日收益| < 9.5%）；次日开盘未涨跌停（可执行）。
- **收益**：`fwdo_N` = 次日开盘买入到 t+N 收盘（N ∈ 1, 2, 5, 10, 20）；同时报 `fwd_N`（收盘到收盘）作对照。
- **成本**：单边佣金 0.025% ×2 + 印花税 0.05% + 滑点 0.05% = 往返 0.15%；净收益 = 毛 − 换手 × 成本。
- **方向**：**每个因子两个方向都报，不事后翻号**。ICIR 为负一样是发现（Fade）。
- **多重检验**：本轮测的因子总数在结果里写明；用 |ICIR| 排序后，**只有同时在样本内、样本外同号且样本外 NW-t ≥ 2 的才算候选**。

## 四、成功判据（写死）

- 候选因子：样本内 |ICIR| ≥ 0.3 且 NW-t ≥ 3；样本外同号且 NW-t ≥ 2；中性化后 ICIR 不低于原来的一半。

## 六、结果一：盘口特征电池（daily_ref，1122 天，样本内 2022–2024 / 样本外 2025–2026）

- 宇宙、成本、方向按第二节。18 个因子 × 6 个持有期，两份完整表在 `research/eval/out/daily_ref_IS|OOS/battery.md`。
- **`imb10_closecall`（收盘竞价后十档失衡）**：原始 IC 样本内 0.052（fwd_20，ICIR 0.79），样本外同号；**但对 log_amt20 / mom20 / ret1 中性化后样本内翻为 −0.033、样本外 +**。⇒ 它主要是小市值 + 反转的影子，不是独立的 Level-2 信号。
- **`amt_share_closecall`（收盘集合竞价成交占比）**：负向，中性化后样本内外同号（IC −0.017～−0.019，样本外多空 Sharpe −2.4～−2.7）。方向与光大 OCVP 一致。但分钟线即可算，且日频换仓扣费后为负；持 10 日的低档净收益样本外 +11.7%（未验证组合层面）。
- `log_amt20` 负向（小市值），`mom20` 负向（反转）：A 股 2022–2024 的已知基线，样本外仍同号但弱化。
- **结论**：仅靠十档快照的日级聚合，没有一条在中性化后既稳定又能扣费盈利。Level-2 的价值必须在逐笔层（flow 面板）验证。

**怎么读**：
- 纯多头相对等权宇宙的超额 +7–8%/年、跟踪误差 3–4%、五年全正——这是一个**指数增强型**的可用信号；对冲掉 β 后剩的就是这 7–8% 减对冲成本。

  取样日只有 1/3（补齐后应做日频再验，`flow_fill.log` 在后台补）。
