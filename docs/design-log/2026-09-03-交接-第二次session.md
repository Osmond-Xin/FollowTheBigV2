## 一、今天用户裁定了什么

1. **事件定义收口**（`2026-09-03-事件流设计收口.md`）：事件三型（区间 / 组 / 时刻）·
   回看范围四档（段内 / 日内 / 跨日 / 周期）· **边界由结构触发不由时间触发**（原话：庄家不掐表，
   是子弹打光了或者量到了）· 每类事件一张表 · 周期型落日级参考层的列 · 提取参数只能是拓扑量 ·
   不得用「反常」定义事件。**污染级别三档**：`unaware` / `knows_prior` / `knows_verdict`，
   按「知道多少」分不按「是否看过」分，且是**参考值不是判据**。

2. **不许按工程方便砍业务需求**（当场纠正）：不同事件本来就该有不同的提取器，
   串行的活给串行提取器，并行的活给并行提取器，**按需选不按贵贱选**。
   我曾以「跨日会串行、多流贵」为由主张把第一批种子从 5 条砍到 3 条——错，
   而且前提也错：按天推进是 4 IOPS 机械盘的存储布局逼的，不是跨日依赖逼的，T−1 零成本。

3. **「把数据挪到另一张表」不叫设计**（当场退回）：上一版 `QuoteThenWithdraw`
   「一笔委托被整笔撤销」是单行属性判断，坍缩比 1:1，信息密度为零。
   **过滤 ≠ 提取**：过滤挑单条记录，提取找多条记录之间的结构关系。

4. **假墙的定义要用数据回归出来，不由我们指定。**

5. **系统里所有代码都不许重复造轮子、不许从零开始，必须调其他模块。**
   五条硬约束一条都不许过。

## 四、实测数字（2022-01-04，200 只随机主板标的，带收据）

收据在 `.lineage/receipts/`，工具 `probe_walls`。

```
读入 orders 712 万 · trades 594 万 · xinqing 86 万，耗时 31–39 秒
档位生命周期 73,787 段 → 回到零 19,006 → 假墙候选（回零 ∧ 零成交）9,175
= 46 条 / (标的·日)。关联不上的撤单 0 / 1,756,341
```

**按峰值时刻的可见档位**（决定性的一维）：

| 可见档位 | 段数 | 假墙候选 | peak_vol 中位 | 建墙笔数中位 |
|---|---|---|---|---|
| **不在十档内** | 59,763 | **8,218（90%）** | 5,100 股 | **6 笔** |
| 第 1 档 | 4,908 | 323 | 19,100 股 | 41 笔 |
| 第 2–3 档 | 3,844 | 301 | 2.0–2.4 万股 | 41–46 笔 |
| 第 4–7 档 | 3,566 | 228 | 3.1–5.5 万股 | 51–58 笔 |
| 第 8–10 档 | 1,706 | 105 | 5.4–6.9 万股 | 40–50 笔 |

**两类形态完全不同**：看不见的是深处零散挂单被撤（6 笔、51 手）；
十档内的是 1.9–6.9 万股、40–58 笔堆起来的。
附带事实：十档内 peak_vol 随档位加深**单调上升**。

**密度落点**：全部 46 / 十档内可见 **4.8** / 必须到过最优价 1.6（条·标的·日）。
⇒ **数据否定了「必须到过最优价」**——只剩 1.6 条，98% 的结构被扔掉。
⇒ 该切的一刀是**可见性**。

**红队的量级估算错了一到两个数量级**：agy 估 500–1500，codex 估 100–1000，实测 46。
它们和我上一版拍的「预算 20 万」一样是猜的。**红队的数字也要验，不能直接采信。**

## 六、坑

- **词汇门禁飘，两种失败模式**：① 同文件同内容同基线，一次报 8 处冲突、一次通过；
  ② 「判定输出不是合法 JSON」。语义判定由 MiniMax 出，有随机性。**重跑即过**，但这是硬门禁，
  CI 可能红在上次绿过的 commit 上。未修。修法：判定输出加 schema 校验 + 重试；
  「判定不可用」与「判定为冲突」分不同退出码。
- **`bash tools/gate.sh | tail` 会把退出码吞成 `tail` 的 0**，门禁红了也照样往下走。
  本 session 因此在门禁红的情况下提交过一次。**门禁不许接管道判成败。**
- 记录已删的生造词时，**不要在文档里复述那个词**——记录也是文本，词汇门禁照样抓。
- 红队脚本 `design` 模式的产物文件名日期取自脚本内部，可能与实际日期差一天。
- **合成夹具全都「正常闭合」时测不出边界 bug**：`closed` 那个 bug 是在真实读取路径上跑出来的。
- **抽样别用 row group 的 `symbol_min`/`symbol_max` 当标的全集**——那只是每个 row group 的边界值。
