## 一、这份对照要说的一件事

**三条全部通过准入。合计 63.90 条/(标的·日)，预算 100。成本闸说一切正常。**

**集中度说其中两条是市场纹理，不是谁的痕迹。**

| 条目 | 条/(标的·日) | 坍缩 | **零率** | 前 10% 占 | 单票最多 | 单条准入 |
|---|---:|---:|---:|---:|---:|---|
| 假墙 `LevelBuildThenVanish` | 26.93 | 2,175 | **27.8%** | 65.2% | 428 | ✅ |
| 冰山 `RefillAfterFill` | **4.28** | 13,683 | **52.9%** | **71.5%** | 120 | ✅ |
| 隐藏深度 `FillExceedsDisplayed` | 32.68 | 1,793 | **2.5%** | **33.6%** | 196 | ✅ |
| **合计** | **63.90** | | | | | ✅ 预算 100 |

- **零率** = 当天一条都没有的标的占比。庄做的是某只股票的某个阶段，它的痕迹应当在大部分标的上**不出现**。
- **前 10% 占** = 事件最多的 10% 标的贡献了多少事件。完全摊平 = 10%，完全集中 = 100%。

**隐藏深度：97.5% 的股票-日都有，且几乎摊平（33.6%）。** 这是市场纹理的定义。
**假墙：72% 的股票-日都有，单票一天 428 次。** 同类。
**冰山：一半以上的股票-日没有，前 10% 的票贡献 71.5%。** 只有这条的形状对。

> **这份对照最重要的用途不是排序，是证明成本闸问错了问题。**
> 密度上界 100 是从常驻预算推的——它回答「装不装得下」。
> 而项目要的是「能不能跟着庄赚到钱」，那个问题由零率与集中度回答，
> 成本闸对它一无所知，还给全部三条发了通行证。

## 二、路上修掉的一个 bug，让此前的数字全部作废

`depth_deltas` 只按 `ord` 排序，没有 `time_ms`。而 `ord` 是**分流编号**（orders 0…n−1，trades n…），
于是一个档位上「全部 orders 的行」会整体排到「全部 trades 的行」之前，时间顺序被打乱。

深交所的撤单在 trades 流里，所以「挂 300 → 撤 → 再挂 300 → 再撤」这两段独立的生命周期
被并成**一段 peak 600、两笔委托两笔撤单**的假象。段数少算、峰值多算、笔数多算。

**注册表本来就声明了 `TOTAL_ORDER = (time_ms, source_row_ord)`——是实现没照着自己声明的排序键排。**

修复后假墙从 3.68 → **26.93**，差 **7.3 倍**。此前 design-log 里假墙的密度与形态数字全部作废
（十档内外的 peak_vol / n_adds 对比也建在合并后的段上）。

**教训**：注册表声明了排序键，但没有任何东西检查实现有没有遵守它。声明与实现之间缺一道对账。

## 三、冰山换机制：218.92 → 4.28（51 倍）

用户 2026-09-03 指出「这么多条说明计算方法有问题，肯定把常见情况也算成冰山了」。缺陷是具体的：

冰山的机制是**同一个人**吃完一片补一片，而逐笔数据里**没有账户身份**。
上一版拿「同价 + 同量」当身份，实际数的是「同一价位上碰巧同量的委托，其中一笔被吃过」——
张三挂 300 被吃掉、李四十秒后也挂 300，算一轮。

改为**档位深度的循环**（被一笔委托堆起来 → 被成交整个吃光 → 回到零 → 同幅度再来），
用「档位归零」替代身份：中间没有别人，补上来的只能是同一个人。

| | 密度 | 坍缩 | 零率 |
|---|---:|---:|---:|
| 同价同量的委托（原始） | 218.92 | 268 | — |
| ＋每片超过一手 | 55.25 | 1,061 | — |
| **换成档位深度循环** | **4.28** | **13,683** | **52.9%** |

## 四、外部证据（详见同日两份调研）

三条事件从来没有过外部锚——四条种子**全部**是 V1 自己失效的检测器（`v1_audit` 字段逐条记着），
全仓没有一条微观结构文献引用。调研补上的部分：

1. **A 股没有交易所级隐藏单 / 冰山委托。** 深交所交易规则 3.2.5 / 3.3.4、上交所 3.2.8 / 3.3.4
   穷举申报类型，无此条款。⇒ **隐藏深度在 A 股没有对应机制**，那 32.68 条是 3 秒采样噪声。
   这条不是收窄的问题，是删除的问题。
2. **方向可能是反的。** Bucci et al.（ANcerno 800 万母单）：母单冲击当日收盘残留 2/3，
   约 **50 个交易日**衰到峰值 1/3。本项目持有期（周–月）**整个落在这个衰减窗口里**。
   ⇒ **全部的边缘都在「还没做完」与「刚做完」的区分上**，而现有三条事件**没有一条有这一维**。
3. **跨日母单长度分布没有公开实证。** 学术 metaorder 文献按构造排除跨日（东交所全市场普查明文
   「不同交易日的市价单视为分属不同 metaorder」）。⇒ 我们的密度上界没有外部基准可对。
4. **方向类因子在我们的持有期上无效。** 华泰 2018 测 10 日持有：净主动买入 / 开盘 / 尾盘 /
   尾盘主力净流入，四类 IC 与 t 值全低。「规模维度才有信息」。
5. **建榕量化 2024**：主力资金因子的 IC 峰值原本在第 15 个交易日（≈3 周，正是本项目持有期），
   **2016 年后消失**。本项目数据是 2022 年。
6. **存在性证明**：广发 Level-2 系列明确 20 日换仓，241 因子中 RankIC>8% 的有 50+ 个。
   ⇒ 逐笔数据能做出 20 日尺度的 alpha——**但那是逐笔流的日频聚合，不是订单簿形态识别**。
   我们这三条所在的方向，公开证据里一条支持都没有。
