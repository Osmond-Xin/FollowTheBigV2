## 工具链上学到的

- agy 无头模式：读文件会被自动拒绝，`--dangerously-skip-permissions` 被本机策略拦截 ⇒ 把对象内联进 `-p`，让它回传代码块。
- opencode plan agent：只读、能自己读仓库；写文件与 /tmp 都会被拒；要它输出代码必须明说「不要调用 bash，直接给代码块」。
- MiniMax API：输出若以 `[` 开头会只回一个 `[` 就 end_turn（稳定复现）⇒ 词汇门禁改为 `{"findings": [...]}`。
- 词汇门禁的语义判定有运行间波动（同一行偶尔一次冲突一次合法）；已加上下文行、分批、温度 0；仍需观察。
- 在隔离 worktree 里**不要用 `git add -A`**：剥离的 docs/.claude/.github 会被当成删除提交（本轮发生过一次，已恢复）。
